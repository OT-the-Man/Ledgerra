# Ledgerra

Data pipeline over African economic indicators (World Bank, IMF and others, pulled through one API). Formerly "Africa Data Bank Pipeline". The plan, phase checklist and progress log are kept in a private notes vault.

## Phases
0. Setup — API key, environment, first raw pull
1. Data Analyst foundations — Python/pandas, SQL, Excel, Git
2. Data Analyst depth — advanced SQL, Power BI, Python automation script
3. First Data Engineering elements — AWS S3, Docker
4. Orchestration + warehousing — Airflow, dlt, Snowflake, dbt
5. Big data processing + quality + hosting — PySpark/Databricks, Delta Lake, Great Expectations
6. Conditional (post-Phase-5) — Terraform, Kafka, CI/CD
